# 番茄投稿助手 (fanqie-tougao)

一个 [ZCode](https://zcode.ai) 插件：把本地或线上写作平台的书稿发上**番茄小说**（fanqienovel.com）。
通过浏览器自动化（CDP）操作你**已登录的日常 Chrome**，不逆向任何接口、不碰番茄的 API 风控。

## 它做什么

工作流分两个阶段，职责严格分开：

**阶段一 · 建书**（不需要稿件）
- 收集固定字段：书名（≤15字）、签约模式、目标读者（男/女频）、阅读标签、内容标签、主角名（2×5字）、简介（50–500字）、封面
- 标签直接查内置**固定值库**选（2026-09 从番茄创建页现场抓取的全量可选项：阅读标签 主分类21/主题24/角色41/情节93；内容标签 情节144/情感58/人设94/世界观60），不用每次重新爬面板
- 简介自动改写成**面向读者的书城文案**（钩子+卖点+悬念，不剧透结局/反转），改写稿经确认后才填表
- 表单填完截图回显，**你点头才点「立即创建」**
- 封面自动上传（含 2:3 规格校验）

**发章节**（独立任务，另行触发）——交接给配套扩展，不重复造轮子
- 首选路径：把整本 TXT 下载到本地交给用户的配套浏览器扩展「番茄发文助手」（整本自动切分、断点续传、弹窗斩杀、定时/直发/仅草稿三模式、悬浮进度面板），扩展运行期间 agent 不碰番茄标签页
- 兜底路径：扩展不可用时才用内置脚本手工拆章逐章粘贴（支持 `第X章`、楔子、番外、markdown 标题，纯 Python 标准库），**默认全部存草稿**，发布永远由你人工决定

**扫描修库**（独立任务，仅明确要求时）
- AI 痕迹 / 英文混入 / 内容泄漏（思考链标签、元信息、残 tag）扫描，用户不要求就不做

## 安装

### 方式一：作为插件市场添加（推荐）

1. 克隆本仓库（或下载解压）到本地任意目录
2. ZCode → 插件市场 → 添加 → 添加插件市场 → 粘贴**本仓库根目录**（含 `marketplace.json` 的那层）
3. 个人 → aiastia-zcode-plugins → 番茄投稿助手 → 安装

### 方式二：手动安装

把 `fanqie-tougao/` 整个目录拷到你自己的插件市场目录（或 ZCode 支持的技能目录）即可，核心就是一个带 SKILL.md 的技能包。

## 使用

安装后新建任务，在技能选择器里选「番茄投稿助手」，然后：

```
给《书名》建书：书籍信息在 ./书籍信息.md（或：墨语项目 ID 149）
```

```
发章节：稿件在 ./全文.txt，全部先存草稿
```

技能按任务线干活：建书阶段不碰你的正文；发章节会先把 TXT 备好交给番茄发文助手扩展（推荐装好它），扩展没装才手工拆章。

## 内置的安全纪律

- 浏览器自动化只走调试协议，**绝不重启/杀掉你的 Chrome、不发全局按键**
- 未登录时停下来等你手动登录，绝不代填账号密码
- 出现验证码/风控弹窗立刻停，交还给你处理
- **不碰账号设置、不点签约、不动任何涉及钱和合同的入口**
- 正文一个字不改，只拆分与搬运
- 一切「发布/立即创建」类动作必须逐次人工确认

## 已知边界

- 番茄前端会改版：技能里的页面流程文档和标签固定值库标注了快照日期（2026-09），页面对不上时技能会现场重新观察并提示你回写
- 标签面板是 React 组件且状态异步提交，技能内置了实测踩坑换来的点选 playbook（弹层打开、元素定位、事件序列、逐个验证），换自动化工具时参考 `skills/fanqie-tougao/references/fanqie-create-flow.md`
- 需要本机有 Chrome + 浏览器自动化通道（如 Chrome DevTools 调试端口）与可用的浏览器控制技能

